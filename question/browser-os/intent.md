# Browser OS

Using HTML, CSS and JavaScript, build a browser-based desktop OS with the following features:

- A windowed desktop shell: desktop icons, draggable windows, and a taskbar.
- A notepad with multiple named documents persisted in localStorage.
- A standard calculator.
- A Minesweeper game with three difficulty levels.
- A Spider Solitaire game (one suit).
- Switchable desktop wallpaper (built-in presets).

Modern flat design (Windows 11 / macOS style), all UI text in English.
