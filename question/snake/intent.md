# Snake

Using HTML, CSS and JavaScript, build a playable Snake game with neon/geometric visual style, following the standard snake rules.

- Start menu: session high-score, configurable board size (default 20×20, min 10, capped by viewport), "Start Game" button.
- After start, a "press any key to begin" overlay; gameplay begins on key-down.
- Controls: Arrow keys and WASD.
- Real-time score display; game over on wall/self collision.
- Session high-score tracking (no localStorage).

Neon/geometric aesthetic, all UI text in English.
